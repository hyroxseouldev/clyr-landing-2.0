# 클리어데브 디자인 검수 — 2026-09-09

기존 다크 테마, 프로젝트 이미지, 콘텐츠와 shadcn/ui를 유지한 개선입니다. 실제 화면 캡처 후 수정하고 로컬 Chromium에서 재검수했습니다.

## 화면별 결과

1. **헤더·첫 화면 — 개선 완료.** 모바일 hero의 이중 32px 여백 때문에 이름과 설명이 부자연스럽게 분리되었습니다. 여백을 한 번만 적용하고 한글 단어 단위 줄바꿈, CTA 가로 배치를 적용했습니다. 헤더 flex 구조는 유지했습니다. [수정 전](before-390-top.png) · [수정 후](after-390-top.png)
2. **협업·성과 — 유지 및 가독성 개선.** 승인된 로고와 수치를 그대로 유지하고 보조 텍스트 대비를 높였습니다. 고정 최소 높이를 제거해 불필요한 공백을 줄였습니다. [화면](after-390-numbers.png)
3. **서비스 — 개선 완료.** 태블릿의 좁은 2열을 960px 미만에서 1열로 전환했습니다. 세 가지 서비스와 문의 연결은 유지했습니다. [화면](after-390-services.png)
4. **프로젝트 — 개선 완료.** 640–1199px는 2열, 모바일은 1열, 넓은 데스크톱은 기존 4열입니다. 상태 배지 줄바꿈, 카드 본문 확장, 기술 라벨 크기를 정리하고 이미지 지연 로딩을 적용했습니다. [화면](after-1440-books.png)
5. **문의·푸터 — 개선 완료.** 태블릿 문의 폼은 1열로 확장하고 모바일에도 직접 연락 카드를 표시합니다. 입력 글자는 16px, 자간은 기본값으로 수정했습니다. 이메일·GitHub를 유지했습니다. [수정 전](before-768-contact.png) · [수정 후](after-768-contact.png)

## 모션·키보드

- Framer Motion LazyMotion: 첫 화면, 섹션 제목, 프로젝트 카드에 18px 이동 + 페이드 등장. 카드는 짧게 순차 등장합니다.
- reduced-motion 설정에서는 등장 이동과 CSS 모션을 끕니다.
- 모바일 메뉴 Escape 닫기 및 버튼 포커스 복귀, 본문 건너뛰기 링크, 이름·이메일 자동완성을 추가했습니다.
- [Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md)의 반응형·포커스·입력·모션 기준도 참고했습니다.

## 검증

- Chromium 320 / 390 / 768 / 1024 / 1440px: 문서 가로 넘침 없음.
- 모바일 메뉴 열기, Escape 닫기 통과.
- 문의 성공 UI 통과: API를 모킹했으며 실제 이메일은 보내지 않았습니다.
- reduced-motion: 프로젝트 카드 opacity 1, transform none 확인.
- 프로덕션 빌드, Sites 패키징 테스트 4개, 문의 API 테스트 4개 통과.
- 실제 iPhone/Safari, 저사양 기기의 프레임 속도, 스크린리더 전체 탐색은 미검증입니다. 접근성 인증이나 실기기 검수 완료를 뜻하지 않습니다.
